# Tenmayurika

Локальный ИИ-workspace для Windows с заметками, задачами и подключаемыми базами данных.

## Запуск

1. Установите Node.js LTS (рекомендуется 22).
2. Скачайте репозиторий и запустите `Tenmayurika.bat`.
3. Откройте `http://127.0.0.1:5173` — BAT также открывает браузер.

## PostgreSQL + Qdrant + Neo4j без Docker

Все три сервиса устанавливаются отдельно (локально на Windows либо на доверенных серверах). BAT **не устанавливает серверы баз данных**: он устанавливает только Node.js-зависимости приложения.

Скопируйте `.env.example` в `.env` и заполните:

- `DATABASE_URL` — строка подключения PostgreSQL, например `postgresql://user:password@127.0.0.1:5432/tenmayurika`. PostgreSQL хранит заметки и задачи; таблица создаётся автоматически. Если переменная пуста, используется `data/workspace.json`. При первом подключении PostgreSQL данные из JSON импортируются, только если таблица ещё пустая. JSON остаётся как резервная копия.
- `NEO4J_BOLT_URL`, `NEO4J_USER`, `NEO4J_PASSWORD` — подключение к Neo4j. При создании заметки автоматически создаётся/обновляется узел `TenmayurikaNote`.
- `QDRANT_URL`, `QDRANT_API_KEY`, `EMBEDDING_URL`, `EMBEDDING_API_KEY`, `EMBEDDING_MODEL` — векторный индекс заметок. Сервис embeddings должен поддерживать совместимый с OpenAI API запрос `{model,input}` и ответ `data[0].embedding`. Коллекция `tenmayurika_notes` создаётся автоматически при первой индексации.

В «Настройки» доступна проверка подключений `/api/services`.

**Ограничения текущей версии:** индексация Neo4j и Qdrant происходит при создании новых заметок, не при миграции старых. Сбой индексации записывается в лог сервера, но не откатывает сохранение в PostgreSQL. Автоматические повторы, семантический поиск, графовые связи и синхронизация удалений пока не реализованы. Qdrant требует работающий embedding API. Не размещайте сервисы баз данных в открытом интернете без аутентификации и TLS.

Секреты храните только в локальном `.env`, который исключён из Git. Проверка: `npm test`.
