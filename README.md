# Tenmayurika

## Запуск на Windows

1. Установите Node.js LTS.
2. Скачайте проект целиком.
3. Дважды нажмите `Tenmayurika.bat`.

Загрузчик проверяет Node.js и npm.cmd, устанавливает зависимости при отсутствии `node_modules`, затем запускает `npm start` либо `npm run dev`.

**Приложение пока не добавлено.** До появления `package.json` BAT выводит понятное сообщение вместо ошибки запуска.

Ключи API нельзя сохранять в BAT или GitHub.
